# 体检后管理 V3.0 工作副本

> V3.0 现行复查口径与验收场景见 [PRD-V3.0-复查口径对齐.md](PRD-V3.0-复查口径对齐.md)。下方“原 Demo 说明”和早期修改记录仅保留历史，不作为 V3.0 复查状态、结果判定、计划覆盖或召回生成规则。飞书与 GitHub 同步状态尚未核实。

## 2026-10-21 本轮标注：复查结果、状态样例与召回详情

- 已告知待跟踪、持续跟踪、已转诊各新增六份独立虚构报告，分别覆盖待复查、待确认、部分已复查、已复查、已取消、无需复查。状态按计划、结果日期与医生确认结论计算；每份有计划的报告只生成一张“生化”异常复查单，只有标记需要医助通知的单生成召回任务。新增样例不覆盖已有演示操作，重置后仍可恢复。
- 持续跟踪信息只展示最近一次跟踪日期及本次新增复查项目；点击项目定位到同份报告“复查计划”中的对应任务。复查计划逐项补充指标原始类别、正常范围及已确认结果，异常结果标红。
- 复查结果确认弹窗标题后显示数据时间范围，结果区取消重复标题与分隔线，检验检查结果按日期时间轴展示。样例包含不同日期的已计入、不匹配、待确认结果；每张检验检查单可独立作出确认结论。
- 取消任务弹窗将停止任务的提示单列为蓝色说明，取消原因限制 100 字并显示实时字数；计划卡片的取消按钮与状态标签等高。
- 召回详情默认先展示复查计划，拨号记录继续使用检后追踪同一时间轴组件。已通知的虚构历史可显示模拟录音；通知结果和计划复查日期用红色星号标必填，结果备注及改期原因不显示“选填”，字段间距统一。
- 召回通知列表在通知状态后展示复查项目、复查进度、复查状态三列，取同份报告关联的异常复查单汇总。
- 已核对内联脚本语法、六种状态在三个追踪页签的实际计算，以及本地 HTTP 预览 200；浏览器截图检查了初始桌面页。未同步飞书或 GitHub。

## 2026-10-21 本轮标注：详情操作与召回改期

- 已告知待跟踪、持续跟踪的检后追踪详情恢复“跟踪结束 / 持续跟踪 / 转诊”；已转诊详情恢复“跟踪结束”。异常复查详情不显示这些流程按钮。
- 复查计划中的“取消任务”改为常规次级按钮；异常复查列表中的“取消任务”与“查看”采用相同的文本按钮样式。取消仍需填写原因，关联任务更新规则不变。
- 未通知召回选择“改期”时展开必填的计划复查日期与选填的改期原因。通知结果必填，结果备注选填。保存后所选复查单的计划应复查日期和应提醒日期同步更新，历史保留原日期、新日期和改期原因；“联系失败”继续保留未通知待办，其余通知结果进入已通知。
- 本轮通过脚本语法检查，HTTP 预览返回 200；右侧打开请求返回 `queued`，尚不能据此确认标注面板实际展示。未同步飞书或 GitHub。

## 2026-10-21 本轮标注：筛选、详情与结果时间轴

- 已告知待跟踪、持续跟踪、已转诊及异常复查的“复查状态”筛选统一为未完成、待确认、部分完成、完成、取消。原七种精细状态仍用于单据计算与标签展示；逾期状态归入对应的未完成或部分完成筛选。未设置计划的报告不落入这五类。
- 异常复查页删除顶部面包屑和演示说明区域；从该页打开的详情抽屉不再展示底部的跟踪结束、持续跟踪、转诊操作。
- 复查结果确认弹窗补充告知日期至总检日期后 365 天的检验检查结果时间轴；时间轴中的结果仅供核对，参与确认仍须满足复查计划的匹配规则。
- 详情页签依入口任务排序：异常复查先看复查计划，召回通知先看体检异常，已转诊先看转诊单和就诊记录，其他检后追踪先看体检异常；无对应事实的页签隐藏。
- 会议最终讨论了召回通知按报告 ID 聚合、未通知取最早应提醒任务、已通知取最近完成通知的规则；当前 Demo 仍逐条展示关联通知任务，本轮尚未实现该聚合，不应据此验收聚合行为。

## 2026-10-20 本轮标注：召回通知与复查单选择

- 召回通知的未通知、已通知页签沿用体检人群页签的下划线样式；筛选改称“应提醒日期”，列表改称“最近应复查日期”“最近应提醒日期”。
- 已通知的“通知记录”复用未检人群的通知详情时间线，显示关联召回任务的模拟通话录音、通知人员和通知结果；历史样例使用虚构模拟录音。后续拨号会把通话与该召回任务绑定，手动录入也会保留通知记录。
- 同一次告知或同一次持续跟踪中，检验检查单按单名互斥：某计划已选“生化”后，其他计划的“生化”整单不可选。保存前再次校验；以后重新发起持续跟踪可再次选“生化”，既有计划保留。
- 报告详情页签由报告已有事实决定，顺序统一为复查详情、复查计划、体检异常、就诊记录、转诊单、拨号记录、操作历史；无复查事实、无计划或无转诊事实时不显示对应页签。待告知使用告知处理抽屉的体检异常、拨号记录、操作历史。异常复查从“复查计划”定位本单；召回通知的“查看”进入同一报告详情。

## 2026-10-20 本轮标注：四个追踪页签字段调整

- 已告知待跟踪筛选保留跟踪期限、体检日期、总检日期、类别、告知方式、复查状态、患者搜索。
- 持续跟踪列表依次展示首次/最近跟踪日期、跟踪状态、复查项目、复查进度、复查状态等指定字段；筛选仅保留体检日期、总检日期、类别、复查状态、患者搜索。
- 已转诊列表保留转诊日期、转入医院、跟踪状态及复查三列；增加转入医院筛选。
- 跟踪结束列表改为末次跟踪日期、末次跟踪方式、结束原因、操作人、跟踪状态等指定字段，不在列表和筛选显示复查三列；详情仍可查看历史复查计划。
- 切换追踪页签时清空前一页签的筛选条件，避免旧条件使新页签列表意外为空。

## 2026-10-20 本轮标注：复查项目、进度与状态分列

- 异常复查列表及筛选字段统一称“复查状态”，保留七种单据状态。
- 已告知待跟踪、持续跟踪、已转诊、跟踪结束列表均新增“复查项目”和“复查状态”；“复查进度”改为已复查单据数/未取消单据数。复查状态筛选覆盖四个页签的七种状态及“未设置复查计划”。
- 四个页签均汇总该体检报告历次告知和持续跟踪创建的全部异常复查单。取消单据保留在复查项目与详情中，但不计入进度分母；全部取消时显示 0/0 和“已取消”。
- 报告级状态优先级为：无计划、全部取消、全部已复查、待确认、部分已复查或逾期部分已复查、待复查或逾期待复查。单据内仅部分指标确认也属于报告级“部分已复查”，即使尚无整张单据完成；逾期取任一未完成且应复查日期早于模拟当日的未取消单据。

## 2026-10-20 本轮标注：单据列表、复查时间轴与召回分栏

- 异常复查列表每行只显示检验检查单名称，例如“生化”“B超”，列名为“应复查日期”；在“复查进度”后新增“实际复查日期”，仅显示医生已确认计入的结果日期。
- 复查计划时间轴按应复查日期归并；同日的生化、B超各有独立卡片，展示原始类别、创建时间、应复查日期、实际复查日期、通知状态、复查进度。逐项确认入口继续保留在各单卡片内。
- 复查进度筛选下拉保留五个常用选项：待复查、逾期待复查、待确认、已复查、已取消；进度计算及列表标签仍保留七种实际状态。
- 召回通知改为“未通知”和“已通知”两个页签，各自展示、筛选和导出对应任务；保存通知结果后任务移动到相应页签。
- 虚构样例补齐同一报告的“生化”和“B超”两张任务单，均在 2026-10-05 应复查，刷新现有演示数据即可查看，重置演示后也会保留该样例。

## 2026-10-19 本轮标注：按检验检查单生成任务

- 待告知和持续跟踪可一次选择多张异常检验检查单；保存后每单生成一条异常复查任务，每单按所含异常指标独立计算七种复查进度。空计划不生成任务。仅选择需要医助通知的单生成关联召回任务。
- 异常复查列表的“查看”定位本单，但详情抽屉继续展示同一体检报告的全部复查计划；已告知待跟踪列表逐单显示与异常复查列表一致的进度标签。
- 已检、未检人群均新增“签约医生”筛选；已检列表在责任医生后显示签约医生，未检列表也显示责任医生和签约医生。选项为本人金医生及团队内吴医生、林医生的虚构样例。
- 待告知样例补齐早于、等于、晚于模拟日期 2026-09-28 的告知期限。复查项目选中区显示检验检查单名称；计划卡片的数量摘要改为紧凑行。
- 签约医生和计划单拆分对已有本地演示数据做幂等补齐，不要求重置；浏览器刷新后即可查看。

## 2026-10-19 复查进度、筛选与医生确认

- “已告知待跟踪”的复查进度为单选：待复查、逾期待复查、待确认、部分已复查、逾期部分已复查、已复查、已取消，并提供“未设置复查计划”单独筛选；同一报告有多组计划时，任一组命中即可展示。
- “异常复查”按复查日期、体检日期、总检日期、类别、复查进度、通知状态、设置环节及患者关键词筛选；复查进度、通知状态和设置环节为单选，可分别清空。
- 异常复查列表增加“通知状态”列，按计划组读取关联召回任务；无需医助通知的计划显示“无需通知”。
- 虚构样例覆盖七种复查进度及“无需通知、未通知、已通知”三种通知状态；一组计划独立判定，不靠就诊记录直接判定已复查。
- 计划复查日前后 7 天内，按患者、项目/指标及结果日期匹配候选结果；同一指标有多份结果时选距离计划日期最近的一份。医生在可处理的详情抽屉“复查计划”中逐项确认“计入本次复查”或“不匹配”，后者必须填写原因。保存后记录医生、时间和结论，并重新计算进度；跟踪结束详情只读。

## 2026-10-19 异常复查任务列表
