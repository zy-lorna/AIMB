# 体检后管理 V3.0 工作副本

> V3.0 现行复查口径与验收场景见 [PRD-V3.0-复查口径对齐.md](PRD-V3.0-复查口径对齐.md)。下方“原 Demo 说明”和早期修改记录仅保留历史，不作为 V3.0 复查状态、结果判定、计划覆盖或召回生成规则。当前工作副本对应 GitHub 的 `post-exam-v30` 分支；Netlify 发布状态以站点部署记录为准，飞书同步状态未核实。

## 2026-10-26 对照去重和拨号记录

- 同一体检异常指标已在其他检验检查记录中确认关联或被当前未提交的其他记录选中时，本记录的原结果对照区不再重复显示，也不会再次自动建立同名对应。计划卡片的元信息在空间允许时占满整行。
- 复查结果弹窗删除定位提示和“指标对应可选”说明，仍自动定位到应复查日期前后 7 天的最近结果。
- 召回通知详情的拨号页签显示该体检报告所有实际留存的 AI 电话盒子通话，包括告知电话和医助召回电话；未拨号的手工通知不生成虚构录音。何某华示例有告知及较早的联系尝试，但尚无对应当前复查计划的医助召回电话。

## 2026-10-25 组合开单对照和详情展示

- 组合开单匹配时，左侧对照标题显示体检报告原结果、异常复查项目名和总检日期；右侧显示本次检验检查结果、组合开单项目名及指标总数。两个指标列表各限定高度并独立纵向滚动。
- 检验检查记录标题旁提供原报告预览。展开记录不再重复显示异常数量及预览按钮；未关联异常复查项目时仍只显示异常指标，正常指标可展开。
- 复查计划卡片仅在存在已确认指标对照时显示一道分隔线；没有已确认指标时不显示分隔线。指标对照中不再显示“对应：某指标”，本次结果异常时结果值标红。状态、去匹配和取消任务之间保持相同间距。
- 蒋某岚和组合开单样例增加虚构告知拨号及医助复查提醒拨号。医助通知对应复查计划与召回通知记录；用于演示告知后、应复查日期前的联系时间线，不代表真实通话。

## 2026-10-25 复查结果弹窗与指标对照

- 未选择关联异常复查项目时，展开检验检查记录仅显示本次异常指标；无异常指标默认收起，医生可展开查看。此时不显示对照区占位提示。
- 选择关联项目后，该条记录自动展开。左侧显示体检报告原始异常指标的名称、结果和正常范围，原始无异常指标默认收起；右侧显示本次全部指标，异常在前、无异常在后。
- 选择项目时自动对应名称唯一且单位兼容的同名异常指标。医生可点击已对应的左侧指标解除对应，或先点左侧、再点右侧手动对应其他指标。指标对应可全部跳过，仅确认项目关联也可提交。操作说明仅写在文档中，不在弹窗展示。
- 提交后，只有实际确认的指标对应才显示在该异常复查任务下。每项一行，显示指标名称、体检原值、本次结果值和正常范围；检查项目使用文字结果。未做指标对应时不显示指标明细。
- 对照区不再重复显示“项目名称 · 应复查日期”标题，也不提供“确认同名对应”按钮。复查计划中的“去匹配”按钮与复查状态标签均为 24px 高。

## 2026-10-25 单条复查任务只关联一条检验检查记录

- 同一条异常复查任务一旦在弹窗内关联某条检验检查记录，其他记录中的该任务立即禁选，并标明本次已选记录日期；取消原选择后可在另一条记录选择。
- 已确认关联的任务也不能再关联其他记录，禁选项标明已关联记录时间；提交时再次校验，避免重复关联。同一条组合检验检查记录仍可同时关联不同异常复查任务。
- 叶某宁新增 2026-09-28 的第二条生化＋血常规记录。另增未匹配病例蒋某岚，保留 2026-09-26 与 2026-09-28 两条记录，便于直接演示跨日期互斥；叶某宁原有操作不被重置。

## 2026-10-25 复查项目与指标快速对照

- 从单条复查计划进入结果弹窗，优先定位应复查日期前后 7 天内同项目且最近的一条检验检查记录；范围内没有同项目记录时定位附近其他记录，范围内没有任何记录时定位全量记录中最近的一条并显示提示。仅定位到同项目记录时预选当前任务，日期定位不限制医生选择其他记录。
- 一张检验检查单可关联多条未完成的复查任务。选择项目后逐项目展示体检报告原结果与本次全量结果；原始无异常指标默认收起，本次指标全部显示且异常在前。
- 原始异常指标与本次指标名称唯一且相同，可由医生一次确认同名对应；名称不同的指标通过左、右各点一次完成对应。指标对照可全部跳过，仅关联项目也能确认复查。确认过的指标对照才在复查计划中回显。
- 叶某宁：组合开单、多项目关联、多项同名与不同名指标、原始正常指标折叠。韩某义：已确认复查项目但未保存指标对照。曹某英：已确认项目及指标对照。任某梅：应复查日期前后 7 天暂无结果时的就近定位。
- 所有病例和数值仅为虚构交互演示数据。本轮已做脚本语法和浏览器操作检查，未同步 GitHub、Netlify 或飞书。

## 2026-10-23 医生手动确认与组合开单

- 本期不做检验检查结果自动匹配校验。异常复查任务的筛选与状态仅有“待复查、已复查、已取消”；报告级保留“部分已复查”，不再出现“待确认”。
- 复查结果弹窗展示告知日期至总检日期后 365 天的全部检验检查记录。一条组合开单记录可多选关联多个复查任务；打开项目状态时定位到其已确认结果日期，或与应复查日期最近的结果日期。
- 叶某宁为组合开单演示样例：生化、血常规两条任务均待复查，同一条“生化+血常规”结果可分别计入两条任务。指标级状态仍为不可点击的标签。

## 2026-10-22 复查结果全量核对与取消记录

- 详情抽屉复查计划中的待复查、待确认、已复查标签可打开全量结果弹窗；已取消标签改为不可点击的纯状态标签。弹窗展示告知日期至总检日期后 365 天的全部检验检查单，按时间倒序；打开已复查项定位对应已确认结果。
- 各份已告知报告补充多日期的尿常规、胸片、心电图虚构记录，用于展示与异常复查项目不同的结果。原有同项目结果仍保留；系统匹配时预选建议项，其他结果由医生选择关联。已确认结果保持只读，只有医生确认计入才回写进度。
- 取消任务时写入取消时间和操作人；既有虚构取消样例也补齐历史字段。复查计划卡片和复查详情时间轴保留取消事件及原因。

## 2026-10-22 已告知待跟踪进度说明与取消弹窗

- 取消异常复查任务弹窗沿用复查计划卡片的项目名称、设置来源和元信息排布；停止复查及通知任务的提示显示为蓝色。
- 已告知待跟踪按体检报告一行汇总复查进度：已复查单据数 / 未取消单据数。无计划显示“—”，全部取消显示“0/0”。仅医生确认计入且单据内全部异常指标完成时，单据计入分子；取消单据保留历史但退出分母。
- 复查状态与进度分别展示：待复查、待确认、部分已复查、已复查、已取消、无需复查；逾期作为待复查或部分已复查的醒目提示。筛选即时按报告汇总状态刷新列表，点击“去跟踪”打开同份报告详情，复查计划展示其全部历史单据。

## 2026-10-21 本轮标注：复查结果、状态样例与召回详情

- 已告知待跟踪、持续跟踪、已转诊各新增六份独立虚构报告，分别覆盖待复查、待确认、部分已复查、已复查、已取消、无需复查。状态按计划、结果日期与医生确认结论计算；每份有计划的报告只生成一张“生化”异常复查单，只有标记需要医助通知的单生成召回任务。新增样例不覆盖已有演示操作，重置后仍可恢复。
- 持续跟踪信息只展示最近一次跟踪日期及本次新增复查项目；点击项目定位到同份报告“复查计划”中的对应任务。复查计划逐项补充指标原始类别、正常范围及已确认结果，异常结果标红。
- 复查结果确认弹窗标题后显示数据时间范围，结果区取消重复标题与分隔线，检验检查结果按日期时间轴展示。样例包含不同日期的已计入、不匹配、待确认结果；每张检验检查单可独立作出确认结论。
- 取消任务弹窗将停止任务的提示单列为蓝色说明，取消原因限制 100 字并显示实时字数；计划卡片的取消按钮与状态标签等高。
- 召回详情默认先展示复查计划，拨号记录继续使用检后追踪同一时间轴组件。已通知的虚构历史可显示模拟录音；通知结果和计划复查日期用红色星号标必填，结果备注及改期原因不显示“选填”，字段间距统一。
- 召回通知列表在通知状态后展示复查项目、复查进度、复查状态三列，取同份报告关联的异常复查单汇总。
- 已核对内联脚本语法、六种状态在三个追踪页签的实际计算，以及本地 HTTP 预览 200；浏览器截图检查了初始桌面页。未同步飞书或 GitHub。

## 2026-10-21 本轮标注：详情操作与召回改期

- 已告知待跟踪、持续跟踪的检后追踪详情恢复“跟踪结束 / 持续跟踪 / 转诊”；已转诊详情恢复“跟踪结束”。异常复查详情不显示这些流程按钮。

## 2026-10-21 本轮标注：筛选、详情与结果时间轴

- 已告知待跟踪、持续跟踪、已转诊及异常复查的“复查状态”筛选统一为未完成、待确认、部分完成、完成、取消。原七种精细状态仍用于单据计算与标签展示；逾期状态归入对应的未完成或部分完成筛选。未设置计划的报告不落入这五类。
- 异常复查页删除顶部面包屑和演示说明区域；从该页打开的详情抽屉不再展示底部的跟踪结束、持续跟踪、转诊操作。
- 复查结果确认弹窗补充告知日期至总检日期后 365 天的检验检查结果时间轴；时间轴中的结果仅供核对，参与确认仍须满足复查计划的匹配规则。
- 详情页签依入口任务排序：异常复查先看复查计划，召回通知先看体检异常，已转诊先看转诊单和就诊记录，其他检后追踪先看体检异常；无对应事实的页签隐藏。
- 会议最终讨论了召回通知按报告 ID 聚合、未通知取最早应提醒任务、已通知取最近完成通知的规则；当前 Demo 仍逐条展示关联通知任务，本轮尚未实现该聚合，不应据此验收聚合行为。
