# 数据大屏视觉改版前基准

基准范围：会议修改副本的数据大屏，2026 年、省级、默认人群；以下数值为原 Demo 数据，部分模块明确标注为模拟数据。

- 慢病态势：共病患者占比热力图；重点慢病人数、专档患者数、风险分层人数、高风险患者数；共病分布环图、管控状态分级环图、建档纳管情况条形图、四项控制率。原有地图图例为“高风险占比低／省均值／高风险占比高／未知”，此次保留原样。
- 一体化门诊：覆盖率地图；分类覆盖环图及基本保障、强化功能、鼓励探索、未建设图例；门诊服务占比环图及服务人次；医防融合入径率、路径综合执行率；覆盖率与控制率散点图及四象限结果。
- 干预成效：控制率地图；血压、血糖、糖化血红蛋白、血脂控制率的全口径与一体化管理趋势；风险等级迁移；四项指标未检测占比。
- 共用操作：三个大屏页面切换、年份和全屏；地图返回、2D/3D、地市/区县、缩放与复位。门诊散点图可切换指标和查看象限；成效地图可切换指标并查看总结。

改版限定为样式和间距。原 Demo 含模拟值，指标口径及展示结果以现有演示为基准，不代表已确认的业务规则。
